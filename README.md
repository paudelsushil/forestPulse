# forestPulse

Analysing Forest Eco-Pulse from Field and Remote Sensing Data 
A comprehensive toolkit for processing, analyzing and 
    monitoring ecological changes in forest ecosystems using field 
    data and remote sensing imagery. Provides unified access to 
    ecological, disturbance and forest management datasets, along 
    with analytical functions for crown segmentation, canopy 
    structure metrics and vegetation indices derived from RGB drone 
    orthomosaics. Designed to support researchers, ecologists and 
    forest managers in quantifying disturbance events and tracking 
    long-term ecosystem dynamics.
